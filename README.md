# HopWay（跳径）

把「机场中继 → 静态 ISP 出口」这条多跳链路，从手工改 YAML 变成看得见、配得明白的 Windows 桌面客户端。

当前阶段：**P3 —— 订阅管理、可视化多跳编排与 Clash Verge 下发**。

## 桌面客户端

双击 `dist\HopWay-Canvas-v5.exe`，会打开主窗口和置顶的桌面卡片。程序只读取和配置 Clash Verge；系统代理即使指向其他客户端，也不会切换配置来源。

主窗口的“当前链路”只读显示从 Clash Verge 运行配置识别到的链路；“编辑画布”是独立保存的 HopWay 配置，不会自动覆盖客户端。程序尝试通过 Verge 已配置的本地命名管道或本机控制接口查询策略组的选中节点；如果接口不可用，则仅在保存记录与配置匹配时显示“上次保存”。静态出口可能是配置候选，不能单凭画布证明所有流量都经过该链路。可点击刷新按钮重新读取运行配置。

在“编辑画布”中：

1. 添加一个或多个 VPN 订阅，并为每个订阅选择具体节点。当前支持返回 Clash YAML `proxies` 列表的 HTTP(S) 订阅；纯节点分享链接、Base64 节点列表和仅含 `proxy-providers` 的订阅暂不支持。
2. 添加静态 IP，填写 SOCKS5 端口、账号和密码。拖动节点调整位置，从右侧连接点拖线到下游节点，也可以在模块中选择下游。一次下发一条链路，支持 1–4 个 VPN 中继和一个静态出口。
3. 保存画布后点击 **生成配置**。预览会显示链路和隐去敏感字段的配置结构；确认后点击 **一键配置并校验**。

订阅链接、节点配置和静态出口凭证使用 Windows 当前账户加密保存在本机；界面不会回显这些敏感字段。订阅节点被移除后需要重新选择。

程序先在临时目录生成候选，并用本机 Clash Verge 自带的 `verge-mihomo` 校验；不通过不会写入。确认写入前会检查源文件是否改变，并备份原文件。客户端需要已有当前配置。

写入后程序会使用独立临时内核自动探测三次出口 IP，并与填写的静态 IP 比较；这项检测验证生成的链路，不代表正在运行的客户端已生效。**仍需在 Clash Verge 重启内核**，并在客户端的 **静态ISP** 策略组中确认选择预览列出的出口节点。程序在等待期间会自动检查客户端配置和实际出口；关闭面板后可在当前运行会话的画布中重新打开“上次检测”。

中继使用订阅节点的配置副本；订阅更新后需要重新下发。Clash Verge 的候选基于当前运行配置，现有自定义脚本的最终效果需重载后复核。

- 桌面卡片默认是约 320 × 56 逻辑像素的小胶囊；点击链路或上箭头展开为约 600 × 276 的详细卡片，点击右下角箭头收起。在空白处拖动可移动位置；点击左侧图标打开主窗口，小卡片的菜单和大卡片的按钮提供刷新与隐藏操作。
- 大卡片显示本地网络、中继、出口 IP、节点协议和最近一次检测时间；无法读取的信息显示为未知。检测时间是出口探测时间，不是连接运行时长。
- 单击托盘图标可打开菜单，查看链路和最近一次出口 IP、显示或隐藏卡片、打开主窗口、退出程序。
- 卡片可见时每约 60 秒通过 Clash Verge 的本地代理探测出口；隐藏后暂停探测。刷新按钮也可立即探测。
- 中继旗帜依据节点名称识别，并非地理位置检测；节点名称无法识别地区或策略组无单一选择时显示未知。组件也可显示画布所选节点的旗帜，但这不证明客户端正在使用该节点。

需要 Windows、WebView2 Runtime，以及已安装的 Clash Verge `verge-mihomo` 内核用于校验。程序不会开启控制接口、操作代理开关或 TUN；这些仍由原客户端管理。出口 IP 只反映探测域名的结果，不能单凭它证明所有网站都走静态出口。无法读取本地控制器时，保存记录只能代表上次选择。

## 项目的行为边界

- 不写 Windows 注册表代理，不改用户级环境变量；代理开关只由客户端界面控制。
- 不预置静态 ISP 的服务器地址、账号、密码；首次必须手填。
- 不擅自开 TUN。
- 凭证不落日志、不进源码，UI 上一律显示掩码。

## 历史脚本工具

`toolkit\sync-proxy.ps1` 和旧版工具包是保留的历史资产，仍包含旧的多客户端命令行功能；当前桌面程序只通过隔离桥接调用其中的 Verge 暂存逻辑。独立运行原脚本会直接操作客户端文件，与桌面程序的预览和暂存流程不同。

## 目录

- `app\`：Tauri + React 桌面客户端源码。
- `toolkit\`：历史脚本以及桌面端使用的隔离暂存桥接脚本。
- `dist\HopWay-Canvas-v5.exe`：支持大小切换桌面卡片的画布版程序。
- `dist\HopWay-Canvas-v4.exe` 和 `dist\HopWay-Canvas-v3.exe`：之前的画布程序，暂时保留。
- `dist\proxy-sync-toolkit.zip`：保留的历史脚本工具包。
- `archive\`：旧方案与旧备份。

## 扩展脚本

默认出口由 Verge **脚本层**的 `MATCH,静态ISP` 决定，不是规则层。只写规则层时，普通网站可能仍走机场。细节见历史交接文档第 8 节。
